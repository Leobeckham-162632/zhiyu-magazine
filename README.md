# 纸屿文学杂志

ZHIYU Literary Magazine。独立文学展示与技术实验项目，2026 年秋季试刊，无正式刊号。

仓库：https://github.com/Leobeckham-162632/zhiyu-magazine

采用 Astro、TypeScript、Markdown 和 GitHub Pages。初次公开部署验证中；完整页面及中文维护文档会在后续提交补齐。

本地运行：安装 Node.js 24，执行 `npm ci`、`npm run dev`。生产构建执行 `npm run check`、`npm run build`。推送 main 自动运行 GitHub Actions。
